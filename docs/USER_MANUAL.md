# Co2Co 편집기 고객용 사용 매뉴얼

## 편집기란?

Co2Co 편집기는 텍스트, 이미지, 음악, 동영상, 버튼, 섹션을 한 화면 안에 직접 배치하고 수정할 수 있는 홈페이지 편집기입니다.

## 기본 사용 흐름

1. 왼쪽 아이콘 레일에서 페이지, 추가, 레이어, 테마 버튼을 눌러 필요한 패널을 엽니다.
2. 왼쪽 패널에서 추가할 객체를 선택합니다.
3. 캔버스 위에 객체가 생기면 클릭해서 선택합니다.
4. 객체를 드래그해서 위치를 옮깁니다.
5. 우하단 핸들을 잡아 크기를 조절합니다.
6. 오른쪽 편집 패널에서 내용, 색상, 크기, 배경, 투명도를 수정합니다.
7. 저장 버튼으로 현재 상태를 저장합니다.
8. 필요하면 HTML 또는 JSON으로 내보냅니다.

## 패널 사용

- 큰 패널은 기본적으로 숨어 있고, 필요할 때만 화면 위로 떠오릅니다.
- 객체를 선택하면 오른쪽 객체 편집 패널이 자동으로 열립니다.
- 빈 캔버스를 클릭하거나 `Esc` 키를 누르면 열린 패널을 정리할 수 있습니다.

## 화면 영역 이름

- 상단 메인 메뉴바: 맨 위 가로 메뉴입니다. 실행 취소, 다시 실행, 화면 크기, 초기화, JSON/HTML 내보내기, 저장 버튼이 있습니다.
- 왼쪽 세로 메뉴바: 페이지, 추가, 레이어, 테마, 편집 버튼이 세로로 있는 빠른 도구 영역입니다.
- 왼쪽 사이드 조절바: 페이지/추가/레이어/테마의 세부 조절 영역입니다.
- 오른쪽 사이드 조절바: 선택 객체의 위치, 크기, 내용, 색상, 미디어를 조절하는 객체 편집 영역입니다.

왼쪽 세로 메뉴바의 위 4개 메뉴는 왼쪽 사이드 조절바를 열고 닫으며, 맨 아래 편집 메뉴는 오른쪽 사이드 조절바를 열고 닫습니다.

## 실행 취소와 다시 실행

상단 메인 메뉴바의 실행 취소/다시 실행 버튼과 키보드 단축키는 같은 기능을 사용합니다.

- 실행 취소: 상단 ↶ 버튼 또는 Ctrl + Z
- 다시 실행: 상단 ↷ 버튼 또는 Ctrl + Y, Ctrl + Shift + Z
- 객체 추가, 삭제, 복제, 이동, 크기 조절, 텍스트 입력, 색상 변경 등 의미 있는 편집 행동을 단계별로 되돌리고 다시 실행할 수 있습니다.

## 섹션과 블록

섹션이나 블록은 왼쪽 사이드 조절바의 섹션 버튼으로 추가합니다. 추가한 뒤 캔버스에서 위치를 옮기고 우하단 크기 조절 핸들로 크기를 조절합니다. 오른쪽 사이드 조절바에서 배경색, 투명도, 둥근값 등을 조절할 수 있습니다.

## 레이어 기능

레이어는 객체들이 서로 겹칠 때 무엇이 앞에 보이고 무엇이 뒤에 깔릴지를 정하는 기능입니다.

- 맨 앞으로: 선택한 객체를 가장 위 레이어로 올려 겹친 객체 중 앞에 보이게 합니다.
- 뒤로: 선택한 객체를 한 단계 뒤 레이어로 보냅니다.
- 맨 뒤로: 선택한 객체를 가장 뒤 레이어로 보내 배경처럼 깔리게 합니다.

## 히어로 섹션의 예시 버튼

히어로 섹션의 시작하기와 미리보기는 편집기 조작 버튼이 아니라 사용자가 만들 홈페이지 안에 놓인 콘텐츠 버튼 예시입니다.

- 시작하기: 상담 신청, 구매, 예약, 수업 신청 같은 대표 행동으로 연결할 수 있는 버튼입니다.
- 미리보기: 데모 보기, 소개 영상, 상세 페이지 같은 보조 행동으로 연결할 수 있는 버튼입니다.

현재는 디자인용 버튼 객체이며, 이후 링크 주소, 페이지 이동, 미디어 실행 기능을 연결하는 방향으로 확장합니다.

## 추가할 수 있는 객체

- 텍스트
- 버튼
- 이미지
- 동영상
- 음악
- 섹션

## 페이지 기준

- 한 페이지는 스크롤 없이 한 번에 보이는 1뷰 화면입니다.
- 필요하면 최대 3페이지까지 만들 수 있습니다.

## 주의 사항

- 큰 동영상이나 음악 파일은 브라우저 저장 용량 제한에 걸릴 수 있습니다.
- 저장 후 새로고침했을 때 결과가 유지되는지 확인하는 것이 좋습니다.
- HTML 내보내기는 최종 배포 전 반드시 화면을 확인해야 합니다.
